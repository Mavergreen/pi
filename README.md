# `pi` for Mavericks

The [Pi coding agent](https://github.com/earendil-works/pi) for Mac OS X 10.9 Mavericks.

Well, actually, it's just a script named `pi` that does these things for you:

- Fetch and install upstream Pi
- Modify its native Node addon to run under Mavericks
- Use Mavergreen's `fd` and `rg` so Pi doesn't fetch incompatible binaries

## How to use

```sh
curl -fsSL https://github.com/Mavergreen/pi/releases/latest/download/install.sh | sh
```
